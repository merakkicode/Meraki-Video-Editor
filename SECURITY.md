# Security

Report vulnerabilities privately through GitHub Security Advisories for merakkicode/Meraki-Video-Editor. Include affected version, platform, reproduction steps and impact; do not attach confidential media. Meraki Core Team triages reports and coordinates fixes before disclosure. Private reporting must be enabled in repository settings before publication.

The 1.0 release candidate is the currently maintained development line. Media decoders process untrusted files; keep the runtime and dependencies updated. Release binaries are unsigned until signing credentials are configured.
