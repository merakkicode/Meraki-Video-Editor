# Meraki Video Editor 1.0 Release Candidate

Four workspaces for precision editing, node effects, real-time mixing and deterministic delivery.

- Rational multi-track timeline with Split, Trim/Ripple, magnetic snapping and markers.
- GPU transforms, alpha composition, color correction, blur, animated properties, transitions and titles.
- Native audio playback, faders, Mute/Solo, metering, biquad EQ and source waveforms.
- Preview proxies, offline media reconnection and periodic project recovery.
- H.264, H.265 and ProRes delivery with a sequential render queue.
- Windows NSIS/MSI and Linux AppImage/Debian packages; Flatpak packaging for review.

This is a release candidate. See the testing guide for platform evidence and current limitations. Binaries are unsigned. Flathub availability begins only after its independent review and publication. Source and third-party runtime materials accompany the release.
